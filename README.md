# Sajeer F M — Portfolio

Personal portfolio website for **Sajeer F M**, AI & Backend Developer.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks. No dependencies.

## Structure

```
portfolio/
├── index.html
├── css/
│   ├── style.css
│   ├── animations.css
│   └── responsive.css
├── js/
│   ├── script.js
│   └── animations.js
└── assets/
    └── resume.pdf
```

## Features

- Loading screen with SFM initials
- Glass navbar with active section tracking
- Typing effect hero with mouse glow
- Scroll-triggered entrance animations
- Skill progress bars
- Project filter (All / AI / Backend / Web)
- 3D card tilt on hover
- Responsive — desktop, tablet, mobile
- Scroll progress bar + Back to Top

## Setup

Clone the repo and open `index.html` in a browser. No build step required.

```bash
git clone https://github.com/sajeerrr/portfolio.git
cd portfolio
open index.html
```

To enable the resume download, place your PDF at `assets/resume.pdf`.

## Deploy

Works out of the box on **GitHub Pages**, **Vercel**, or **Netlify** — just point to the root directory.
